# Unmarked Ministries website

Live at https://unmarkedministries.org (GitHub Pages).

- `index.html` — the whole site. To update the Founding 120 count, change `SEATS_FILLED` near the bottom.
- `images/` — board headshots.
- `thank-you.html` — shown after the contact form.
- `CNAME` — keeps the custom domain. Do not delete.

DNS lives at GoDaddy. Only the A records for `@` and the CNAME for `www` point here; all email (Google Workspace MX/TXT) records are untouched.
